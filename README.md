# ASAB | عَصَب — AEROLAB 3D

Sovereign Airborne Command & Control with an AEROLAB 3D engineering digital twin.
Theme: espresso-brown surfaces with beige / caramel accents.

## Run
    bun install   # or npm install
    bun run dev   # http://localhost:3000

## Mobile
- Responsive layout (dvh, safe-area, RTL-aware drawer, stacked side panels)
- Installable as a PWA (manifest + icon)
- Pixel ratio capped on phones; simulation pauses when the tab is hidden
